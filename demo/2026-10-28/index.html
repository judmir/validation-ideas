  • Real"Who are your kids?" → names, grades, schools, teachers

    Real AI (claude-haiku-4-5, ~1.5 s). Sample: Mia 2nd · Oak Elementary · Ms. Lopez; Leo 7th · Roosevelt Middle · Mr. Grant. A new family ("Ava, kindergarten, Mrs. Chen…") parses too.

  • RealPaste emails/texts → per-message JSON (kid, relevance mine/district/other grade, needs-action, due, amount, source, via, sender, topic, dedupe key)

    Real AI, in 5-message chunks run in parallel. 19 sample messages: 7.4 s, ~8.0k tokens. Every kid/district/other-grade call was right on the sample. Each needs-action call was right too, except the screenshot's optional book fair, which was marked needs-action.

  • RealScreenshot → same JSON (vision)

    Real AI vision (~4 s, ~2.5k tokens). The bundled MADE-UP ClassDojo screenshot gives 2 posts; its Pajama Day post merges with the ClassDojo app copy.

  • RealDuplicate merging (app + text + email copies)

    Real (client, components/core.ts): AI dedupe key, topic + event date, token similarity. Sample: zoo slip 3 copies → 1, lab contract 2 → 1, early release 2 → 1, spirit week 2 → 1.

  • RealDistrict / other-grade noise muted (smart default: not for a kid → muted)

    Real. Board meeting, spirit week, bus route, flu clinic, 8th-grade volleyball and kindergarten trip are all muted, with reasons.

  • Real"Not for us" → mute rule (sender + topic; PTA/athletics/district = whole sender)

    Real (localStorage). Shows the similar posts it will hide first. Rules are applied before the AI on new imports (no tokens spent), and can be removed in ⚙︎.

  • Real"N things need you tomorrow" + 7 pm line

    Real count; the 7 pm push itself is only a preview line (no notifications).
