All 11 pieces, from the builder's POC note (poc/2026-10-25.md)
  • RealBlog URL import

    Real. Server-side fetch, then a schema.org Recipe JSON-LD parser (no AI). Live test 6/6: loveandlemons.com, minimalistbaker.com, pinchofyum.com, recipetineats.com, bonappetit.com, food.com

  • RealBlog without JSON-LD

    Real. Page text → LLM (tested on a Wikibooks recipe; a non-recipe page is correctly rejected)

  • RealReel import by URL

    Real. TikTok (oEmbed, else the caption in the public page) and YouTube (description) → LLM. Tested on 2 real TikTok recipe videos and 1 YouTube Short. Instagram reads the public og:description; if it's login-walled, you get a "paste the caption" prompt

  • RealCaption paste

    Real (LLM)

  • RealPhoto / handwritten card

    Real (vision LLM). Tested on a rendered handwritten-style sample card: 8/8 ingredients, 4/4 steps

  • RealLibrary, search, tags, card edit-in-place, Export all (JSON/MD)

    Real (client-side, localStorage; export downloads verified in headless Chrome)

  • RealPWA share target

    Real manifest (share_target GET → /?url= / ?text=). The ?url= entry is tested; it was not installed on a real Android phone

  • Note onlyiOS Shortcut

    Note only (the Shortcut would open /?url=<link>)

  • MockedHousehold invite link

    Mock (generates a local link and shares nothing)

  • Fake (demo)Paywall + checkout

    Fake, marked "DEMO · NO REAL PAYMENTS". No card fields, no charge. Free demo plan: 10 AI imports to try; blog links and export are always free

  • Not builtAccounts / sync

    Not built (localStorage only)
